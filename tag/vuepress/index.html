零成本搭建个人博客：VuePress + GitHub Actions + Pages 全流程实战

写了十年 Java，笔记散在 CSDN、博客园、掘金、语雀里，最后发现最难的不是写，而是找回来。于是决定自己搭一个：内容自己管、发布自动化、一分钱不花。

这套方案跑了几个月，每天写、每天发，没出过岔子。把这套流程完整记下来，给同样想"白嫖一套博客"的人少踩几个坑。
